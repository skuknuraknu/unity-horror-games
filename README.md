# 🎮 Unity Horror Games

## 📌 Deskripsi Proyek
Proyek ini merupakan **Tugas Akhir Mata Kuliah Pemrograman Visual** berupa **game horror sederhana** yang dikembangkan menggunakan **Unity** dan bahasa pemrograman **C#**.

Game ini berfokus pada suasana horror, eksplorasi lingkungan, serta interaksi dasar pemain dengan objek di dalam game. Tujuan utama proyek adalah menerapkan konsep pemrograman visual, event handling, dan logika game dalam sebuah aplikasi interaktif.

---

## 🧠 Konsep Game
- **Genre**: Horror / Exploration  
- **Sudut Pandang**: First Person
- **Tema**: Lingkungan gelap dan sunyi dengan elemen kejutan  
- **Tujuan Pemain**: Menjelajahi area dan menyelesaikan objective sederhana

---

## 🛠️ Teknologi yang Digunakan
- **Game Engine**: Unity  
- **Bahasa Pemrograman**: C#  
- **Platform Target**: PC (Windows)  
- **IDE**: Visual Studio
